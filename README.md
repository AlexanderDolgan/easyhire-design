# easyhire-design

Дизайн-спека лендинга **EasyHire.me**, снятая из Figma. Нужна для того, чтобы свёрстанные
в прототипе страницы переделывать под стиль текущего сайта.

📄 **[DESIGN.md](DESIGN.md)** — сама спека, 630 строк. Проверена вторым проходом по узлам Figma (см. историю коммитов).
🎛 **[tokens.css](tokens.css)** — все переменные (цвета, шкала, отступы, радиусы, тени, motion, брейкпоинты) + референсные рецепты компонентов с состояниями.

## Источник

Файл в Figma называется *pizza22*, но секция `147:4152` содержит лендинг **EasyHire.me**
(AI video interview platform). Спека написана по нему.

<https://www.figma.com/design/sXKTv4c2oAjKebp6F22RXW/pizza22?node-id=147-4152>

| Артборд | node-id | Размер |
|---|---|---|
| Desktop landing | `147:3` | 1728 × 7623 |
| Tablet landing | `147:4306` | 768 × 10845 |
| Mobile landing | `147:2123` | 390 × 12810 |
| Sign-up Dialog | `147:4028` | 468 × 781 |

Значения сняты напрямую с узлов через figma-desktop MCP (`get_design_context`), не на глаз.

**Второй источник — живой сайт <https://easyhire.me>** (MUI v5 / emotion). Из его CSS сняты hover / active /
focus / disabled, transitions, breakpoints, cookie-баннер — всё, чего в Figma-слепке нет. Каждое состояние
проверено наведением и чтением computed-styles в браузере, а не только по стилям.

## Чего в спеке нет и почему

- **Токенов/переменных Figma** — их в файле нет вообще (`get_variable_defs` вернул пустоту).
  Это импортированный слепок сайта, поэтому все значения сняты с конкретных узлов.
- **Состояний в Figma нет** — они сняты с живого сайта (раздел 7 спеки). Три оговорки:
  ссылки и карточки на сайте hover не имеют вообще; hover soft-кнопки в шапке — просвечивающий
  MUI-дефолт (кнопка «выцветает»), спека это фиксирует, но разрешает взять поведение тарифных
  soft-кнопок; ripple — MUI TouchRipple, воспроизводить или отключать осознанно.
- **Интерлиньяжи `--h3` / `--h4`** в расширенной шкале достроены (на сайте там `line-height: normal`) — помечено в таблице.
